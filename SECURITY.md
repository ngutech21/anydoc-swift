# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities in AnyDocSwift privately through
[GitHub Security Advisories](https://github.com/ngutech21/anydoc-swift/security/advisories/new).
You can also open the repository's
[Security Advisories page](https://github.com/ngutech21/anydoc-swift/security/advisories)
and select **Report a vulnerability**.

Do not disclose vulnerabilities in public issues, discussions, or pull requests.

Include as much of the following as possible:

- The affected AnyDocSwift version and, if known, the embedded anydoc version.
- Your operating system, architecture, and relevant configuration.
- A description of the vulnerability and its potential impact.
- Reproduction steps or a minimal proof of concept, including a sample document
  when needed.
- Relevant logs or crash reports, with secrets and personal or confidential data
  removed.

Use synthetic or sanitized sample documents. Please coordinate public disclosure
with the maintainers to allow time to investigate and address the issue.

For bugs without a security impact and feature requests, use the
[issue tracker](https://github.com/ngutech21/anydoc-swift/issues).
